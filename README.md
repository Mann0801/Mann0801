# Hi, I'm Mann 👋

I'm a CS student at PES University in Bengaluru. I build backends and automation, and I like working close to Linux. I care most about software that real people use every day.

## What I've built

**[Studio Finance Portal](https://github.com/Mann0801/Studio_Finance_Portal)**: Runs memberships and payments for a real fitness studio, and it's live and in daily use. Members pay their monthly fees from an app on their phone. The owner sees who has paid and who hasn't, records cash payments, and sends WhatsApp reminders with one tap.
`FastAPI` `React` `Supabase` `Razorpay`

**[Hacker News Digest](https://github.com/Mann0801/Hacker_News)**: Emails me the 5 most-discussed Hacker News stories every morning, each explained in plain English by Gemini. It runs on GitHub Actions and costs nothing.
`Python` `Gemini API` `GitHub Actions`

**[Synapse AI](https://github.com/Mann0801/synapse-ai)**: A hackathon backend for a 60-minute fashion delivery platform. It recommends products from a plain-text request, forecasts demand by pin code, and moves stock between small local warehouses before they run out.
`FastAPI` `Supabase` `Python`

**[Supervisor CLI](https://github.com/Mann0801/Supervisor-CLI-and-Signal-Handling)**: A Linux supervisor process written in C. It starts, stops, and lists child processes on commands sent from a CLI through a named pipe, and uses `SIGCHLD` handling to clean up processes that exit.
`C` `Linux` `POSIX signals`

**[SDN Path Tracing Tool](https://github.com/Mann0801/CN_SDN_Path_Tracing_Tool)**: A Ryu controller app that traces the path a packet takes across OpenFlow switches in Mininet, and shows how the network behaves when a link fails.
`Python` `Ryu` `Mininet` `OpenFlow`

**[Attendance Tracker](https://github.com/Mann0801/Attendance-Management)**: A PWA for the same fitness studio. Members mark attendance by scanning a QR code, and admins see attendance stats.
`React` `TypeScript` `PWA`
